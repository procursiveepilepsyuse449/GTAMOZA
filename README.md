## 🔧 Troubleshooting Common Issues

### GTAMOZA Doesn't Open
- Make sure GTA V Enhanced is running first
- Right-click GTAMOZA and select "Run as Administrator"
- Check if your antivirus is blocking it (add an exception for GTAMOZA)

### Wheel Not Detected
- Ensure your Moza wheel is properly connected via USB and powered on
- Check that the official Moza software is installed
- Restart both GTA V and GTAMOZA

### No Force Feedback in Game
- Move your vehicle first—force feedback activates once you're driving
- Try lowering the effect intensity if it feels too strong
- Make sure you haven't accidentally turned effects off

### Game Crashes
- Update both GTA V Enhanced and GTAMOZA to the latest versions
- Close other mods that might conflict
- Temporarily disable your antivirus to see if that helps

## 📜 What's Under the Hood?

For those curious, GTAMOZA is built with modern technology:
- **Electron** framework for the user interface
- **TypeScript** for reliable code
- **Script Hook V** to communicate with GTA V
- **DirectInput** and **UDP** to talk to your Moza wheel
- **Telemetry system** to translate game physics into wheel movements

All this technical stuff happens automatically—you never need to see or understand it!
